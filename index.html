COMMON QUESTIONS

常见问题

我的论文会上传到服务器吗？

普通检查在当前浏览器中处理文件，PaperAudit 没有论文上传服务。可选 AI 功能默认关闭；启用后会从第三方站点下载运行组件和模型文件。不要在公开 Issue 或 PR 中粘贴未发表论文、私人模板或审计报告。

支持哪些文件？

论文支持 Word DOCX；图片检查支持 PNG/JPEG。模板对照可使用支持的 DOCX/DOTX，作者指南可先整理为 TXT/MD。旧版 DOC、PDF 和 LaTeX 源文件不能作为此工具的完整格式检查输入。

显示“通过”就代表符合期刊要求吗？

不是。它只表示当前启用的规则没有发现其能够识别的问题。复杂 Word 自动域、特殊编号、所有引用格式和版面视觉要求都不能保证完整检查。投稿前仍须核对期刊最新官方作者指南。

没有模板也能使用吗？

可以。先用示例论文体验普通检查，也可以使用内置通用预检规则。通用规则不代表特定期刊的官方要求；v0.5.0 的可追溯模板语义升级目前仍在公开 PR 中审查。

怎样帮助改进项目？

请提交可复现的错误步骤、浏览器和操作系统信息，或使用虚构的合成 DOCX 重现编号问题。请不要上传私人论文、未公开的作者指南、个人数据或完整审计报告。前往 GitHub 反馈问题 ↗

你的论文，只留在你的设备里。

本版使用纯静态网页，文件由浏览器本地解析。没有自动上传论文的接口或账号系统。可选的免费浏览器 AI 需要用户明确同意，并从外部站点下载运行组件和模型权重；AI 推理设计为本机执行，但仍需通过真实 WebGPU 测试。只有用户明确点击“保存到我的模板库”时，模板才存放于当前浏览器的本地数据库；仅用户主动生成投稿信息或前往 GitHub 才开始社区贡献流程，且默认只分享来源链接。浏览器清理网站数据可能删除本地模板。
