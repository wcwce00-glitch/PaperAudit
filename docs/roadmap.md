# Roadmap

This roadmap is a prioritization guide, not a promise of delivery dates.

## P0 — Trustworthy results

- Keep a synthetic regression fixture for every confirmed false-positive fix.
- Expand Strict/Transitional OOXML numbering coverage, including restart rules and subfigures.
- Improve traceability for extracted author-guide requirements and preserve verbatim source snippets.
- Keep uncertain visual-layout requirements in review-only status until trustworthy page rendering is available.
- Keep privacy claims aligned with actual browser network behavior.

## P1 — Browser and compatibility testing

- Verify stable checks on current Chromium, Firefox, and Safari/WebKit.
- Test genuine WebGPU model loading and candidate extraction on a supported consumer GPU/browser.
- Document tested browser/OS/GPU combinations and graceful fallback behavior.
- Add more synthetic cases for English and Chinese guidelines, hyperlinks, tables, headings and document sections.

## P2 — Usability and adoption

- Improve the first-run demo and explain each finding with a compact evidence sample.
- Add accessible keyboard navigation and screen-reader labels for the rule report.
- Collect bug reports using text-only reproduction steps; never request confidential manuscripts.
- Make contribution triage and release notes predictable.

## Not planned without a separate design review

- Uploading manuscripts to a server.
- Treating model output as an authoritative publisher requirement.
- Claiming full compliance with a journal from a generic ruleset.
- Hosting or redistributing proprietary publisher templates without permission.
